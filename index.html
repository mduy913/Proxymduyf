HƯỚNG DẪN CÀI ĐẶT
Bước 1 — Cài WebClip:
  1. Nhấn CÀI WEBCLIP (hoặc LƯU .mobileconfig rồi mở file trong Files)
  2. iPhone mở Cài đặt → Đã tải Profile → Cài đặt → nhập mật khẩu → Cài
  3. Ra Home Screen sẽ thấy icon WebClip mở đúng link bạn đã nhập

Bước 2 — Cài UserScript (chạy trên web đó):
  1. Cài app Stay hoặc Userscripts (Safari Extension) từ App Store
  2. Nhấn TẢI USERSCRIPT (.user.js) ở trên
  3. Mở app Stay/Userscripts → Import file vừa tải → bật extension trong Safari
  4. Mở WebClip → UserScript sẽ tự chạy trên web (nếu domain khớp @match)
